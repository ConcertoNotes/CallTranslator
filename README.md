# 通话翻译（Android）

在开着免提的 iPhone 旁边放一台安卓手机，用它实时翻译通话。适用于 WhatsApp、Telegram、Instagram 以及普通电话。

- **听对方**：安卓手机持续听 iPhone 喇叭里对方说的话，**对方边说，中文译文边在屏幕上实时刷新**，一句说完后存成一条气泡（也可以勾选朗读）。
- **我说话**：点「🎤 我说话」，对着安卓手机说中文。它会翻译并用外语大声播放出来，iPhone 的麦克风收到后传给对方。

全部免费：
- 语音识别：手机自带的 Google 语音识别
- 翻译：Google ML Kit 离线翻译，模型下载后可以断网使用
- 发音：手机自带的文字转语音

## 编译 APK（不用装任何开发工具）

1. 注册一个 GitHub 账号，新建一个仓库，把整个 `CallTranslator` 文件夹上传进去（要包括 `.github` 文件夹）。
2. 打开仓库的 **Actions** 页面，等「Build APK」运行完成（约 5 分钟）。
3. 点进这次运行，在页面底部 **Artifacts** 里下载 `CallTranslator-apk`，解压后得到 `app-debug.apk`。
4. 把 APK 发到安卓手机上安装，需要允许「安装未知来源应用」。

## 安卓手机需要满足的条件

- 安装并更新 **Google App**，也就是 Google 语音服务。华为、部分国产机如果没有谷歌服务，语音识别用不了。
- 首次选择语言时要联网下载翻译模型，网络需要能访问 Google。
- 设置 → 文字转语音：引擎选 Google，并下载对方语言的语音包（比如英语）。

## 通话时怎么摆放

1. iPhone 开免提，音量调大，平放在桌上。
2. 安卓手机放在 iPhone 旁边，两台手机的喇叭和麦克风互相靠近。
3. 在安卓手机上点「▶ 开始听对方」，保持 App 在前台，屏幕会常亮。
4. 轮到你说话时，点「🎤 我说话」，对着安卓手机说中文，说完再点一下，或者停顿一下会自动结束。安卓手机会大声播放英文，iPhone 把它传给对方。
5. 对方没听清时，点一下自己那条绿色气泡，会再播放一遍。

## 已知限制

- 每句话大约有 1–3 秒延迟，一次说一两句效果最好。
- 你说中文时，iPhone 也会把你的中文声音传过去，然后对方才听到英文。想避免的话，可以在说中文时把 iPhone 静音，等安卓手机开始播放英文再取消静音。
- 部分手机每次开始识别都会"嘟"一声，这是系统行为。
- 离线翻译的质量比网页版谷歌翻译略差，但日常商务沟通够用。
